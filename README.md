# AI Customer Support & E-commerce Automation System

An AI-powered customer support and e-commerce automation platform.

## Project Overview

This system aims to manage customer conversations from multiple channels, automate customer support using AI, manage products and orders, and provide a unified inbox for human agents.

## Technology Stack

### Frontend
- React
- Vite
- JavaScript
- Bootstrap

### Backend
- Python
- Django
- Django REST Framework

### Database
- PostgreSQL
- pgAdmin 4

### Tools
- VS Code
- Git
- GitHub
- Postman

## Main Features

- Unified customer messaging inbox
- AI-powered customer support
- Product and inventory management
- Order automation with customer confirmation
- Human agent assignment
- Bangla voice message understanding
- Image-based product search
- Sentiment analysis
- Multi-store support
- Sales analytics and forecasting

Currently in the initial environment setup and project structure phase.
